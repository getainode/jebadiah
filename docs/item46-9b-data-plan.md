# ITEM 46: more clean data for 9B

Research proposal, 2026-10-09. No training, evaluation, paid generation or dataset purchases. Web research used TinyFish CLI search and content extraction. **Test better data through fixed-size replacements in A3, one source per run.** Do not copy Nimble data, predictions, weights or its non-commercial run code.

## Admission comes before sampling

The v2.1 manifest was checked against SHA256 `079617f615065a39549faa1b8676ce6a720a9efe8c31c04ebe39df024ca3d172`. Its full source/ancestor exclusions apply, not just names of the 37 scored benchmarks. The edition 0.3 [source catalog](https://github.com/apolinario/decision-index/blob/9eb2dbe2a358004c8782c66e40a83ac07b953fec/docs/suite.md), acquisition definitions and full manifest were inspected, including unscored sources. The manifest downloaded from `jbrashear/decision-index-suite-0.3@e57106b5e0698e74bd1a88b3b4c19b94a0dc8328` is byte-identical to the inspected catalog's suite manifest, SHA256 `e24b2f990ed2220233af19713a13c0a92b3c1756af1991ddf985a3420bf1258c`. New source names below are absent from that catalog and the exclusion list. This is a provenance screen, **not a completed full-suite overlap scan**.

For each source, freeze revision, data and license hashes, original authors, ancestry URLs, terms permitting commercial training and model redistribution, derivation, complete-split counts and attribution/notice text in a per-source manifest. Scan the entire upstream source across all splits before selecting rows, then scan rendered states, instructions and options. Reuse the pinned [full-suite scanner](../data/item33_full_suite_scan.py), index SHA256 `cf54ade9013c05db74f4c70925287382708de965fbf3cba62145ee821adad0ff`. **Any overlap rejects the whole upstream source and its derivatives.** No record-only rescue. Unknown rights or ancestry also means no admission. A lexical scan cannot establish independence from unavailable private tests or undo base-model pretraining.

**Hard rejects:** HoVer/FEVER/HotpotQA and Wikipedia derivatives; ANLI/SNLI/MNLI and their augmentation corpora; CLadder, VAST, iSarcasmEval, CLINC, BANKING77, GSM8K, BBH, POP909 and all their train splits/derivatives. A permissive license does not override contamination. [HoVer's original two-hop claims derive from HotpotQA](https://hover-nlp.github.io/); [FEVER independently derives from Wikipedia](https://fever.ai/dataset/fever.html), so it shares protected ancestry rather than being a clean substitute. The [ANLI repository](https://github.com/facebookresearch/anli) explicitly mixes SNLI, MNLI, FEVER-NLI and ANLI in its training recipe; exclude these families and derived teacher targets, without claiming every original ANLI row is an SNLI copy. FOLIO is rejected for its [CC BY-SA 4.0 and WikiLogic ancestry](https://github.com/Yale-LILY/FOLIO). [x-stance's data are CC BY-NC 4.0](https://github.com/ZurichNLP/xstance#licenses), despite MIT code and an incorrect MIT entry in the v2.1 held-out manifest; do not use it to train or publicly redistribute its data. SARC/news-headline/TV-dialogue sarcasm mirrors were not admitted because independent underlying text rights were not verified. Search/card tags alone are insufficient.

## Run ladder against A3

Priority is an expected-transfer hypothesis, not a forecast of index points. [Item34 gaps](../results/research/item34-public-gaps.csv) compare Nimble's full public panel with Jeb v2's proxy, not A3, and different benchmarks have different weights. Broad evidence/causal/NLI transfer and licensed human intent data precede narrow music/home gains and uncertain pragmatic labels.

Each rung starts independently from the pinned 9B parent and **A3's 21,190 question presentations**, not a previous rung's checkpoint. Replace matched area/type slots, preserve total size and original 512-question calibration bytes, and change only the incoming source. Start at **1,000 replacement questions (4.72%)**, reduced if the matched donor pool is smaller. Keep incoming upstream exposure, including pre-existing A3 rows and all variants/translations, at **10% maximum: 2,119 questions**. The audited A3 file contains 102 Corr2Cause and 102 SpaceNLI questions, leaving 2,017 questions of headroom for each before accounting for removed donor rows. Source families cannot be renamed to evade the cap. Owned skill variants sharing one generator count as one upstream source. Do not increase sequence length, options, epochs, LR, rank or training steps. Hold seed, renderer, temperatures, objective and recipe fixed; check question counts, prompt length and donor/source/type histograms before launch.

Alternatives in the candidate table are substitution proposals for their rung, not extra sources blended into it. Owned OOS can replace rung 4 as its own later experiment. Every rung needs a written pre-run hypothesis and keep/drop rule. **Keep only if the frozen 10% proxy paired whole-group bootstrap 95% interval of candidate minus A3 (46.97) is entirely above zero, with score above v2's 44.67, and the source-specific independent diagnostic improves.** Inspect all five areas and record regressions; retrieval-targeted rung 4 additionally requires a positive retrieval-area interval. Drop failures, never retain a local skill win that fails the overall rule. Combine independently kept changes only in a separately measured run.

N2 lost **4.29 overall** and **14.09 retrieval** despite fixed size. R3 was **-0.06 overall**, and G1 **-0.28**, despite some skill gains; both additions also increased epoch exposure. N3 rank, D0 dropout and L5 LR all failed the keep rule. Better coverage is not automatically better data. Fixed size controls exposure, but replacement can still erase useful behavior, which is why every rung keeps the overall gate.

Costs use the measured item36/item37 A3-sized training plus 11,079-request proxy and $2.75/hour as the planning basis. Typical measured runs were about $3 to $4; **$4 to $6 each** allows setup, merge and a modest recovery allowance. Ten proposals total $40 to $60 if separately authorized; this document authorizes none. Source curation/review has no purchased data or teacher budget. Preserve the unchanged 0.05 export gate and local-hardware CI policy. Existing A3 private contamination exceptions still block public shipment: resolve them through a separately measured source scrub before release, not silently inside a data rung.
